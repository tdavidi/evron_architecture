# מתכננים את הבית עם Claude

נקודת התחלה למשפחה שמתכננת בית פרטי בשכונה החדשה, בדו-משפחתי. כאן יש את כל מה ש-Claude צריך כדי לנהל איתכם את התכנון: לשאול, לשרטט תוכניות בקנה מידה, לבדוק אותן ולהכין הדמיה בתלת-ממד.

המאגר נבנה מהתכנון של הבית השני באותו זוג. שני הבתים חולקים קיר משותף, אותו מגרש ואותם כללים. התוכניות של הבית השני מופיעות כדוגמה בלבד. הבית שלכם מתחיל מהתיאור שלכם.

## מה יש כאן

- **שיטת העבודה** (`docs/00-method.md`): ארבעה שלבים, מהשגרה שלכם ועד סיכום לאדריכל, והלקחים מהבית הראשון.
- **הבריף** (`docs/01-brief.md`): תבנית שתתמלא בשיחה, ועקרונות הזוג, שמשותפים לשני הבתים.
- **המגרש והכללים** (`docs/02-site.md`, `docs/05-building-rules.md`): מידות, כיוון, שמש, קווי בניין, גג, גדרות וחניה.
- **המחקר** (`docs/07-design-research.md`):
  - מה מקובל בבתים בישראל, ומה התקנות דורשות: ממ"ד, חדרים ומדרגות.
  - אקלים, מידות ריהוט וגינה.
  - רשימת בדיקה ותרחישים.
  - שיטות בנייה, עלויות והתהליך מול קבלנים.
- **הכלים** (`tools/house_plan/`):
  - שרטוט בסגנון של תוכניות בישראל: קירות, דלתות, חלונות, ריהוט ושטחים.
  - בדיקות אוטומטיות.
  - דף אינטראקטיבי עם זום והדמיה בתלת-ממד.
- **הדוגמה** (`docs/example/`): חמשת הדגמים של הבית השני, משלוש צורות שונות ועד הגרסה האחרונה.

## איך מתחילים

**הדרך המומלצת: Claude Code.** הוא מריץ את כלי השרטוט ובונה את הדפים וההדמיה. אפשר להשתמש בו בשתי דרכים:
- באפליקציה של Claude למחשב, בלשונית Code.
- בדפדפן, ב-[claude.ai/code](https://claude.ai/code).

**השלבים:**
1. פותחים שיחה חדשה ב-Claude Code, בתיקייה ריקה במחשב.
2. מעתיקים את ההודעה הראשונה שלמטה, ומוסיפים בסופה תיאור של הבית שאתם רוצים, במילים שלכם.
3. Claude ישכפל את המאגר, יתקין מה שצריך, יבנה את הדוגמה כדי לוודא שהכול עובד, ויתחיל לשאול.

**ההודעה הראשונה:**

```text
אנחנו משפחה שמתכננת בית פרטי בדו-משפחתי, בשכונה החדשה בקיבוץ. כל מה שצריך נמצא במאגר
https://github.com/tdavidi/evron_architecture
שכפל אותו לתיקייה הזאת, קרא את README.md ואת CLAUDE.md, ופעל לפיהם. הכן את סביבת העבודה, ובנה את הדוגמה כדי לוודא שהכלים עובדים.
אחר כך נתחיל בשיחת הפרוגרמה: אתה מנהל את התהליך, שואל, משרטט ומכין הדמיה, ואנחנו מחליטים. דבר איתנו בעברית.

הבית שאנחנו רוצים, בקצרה:
(מי גר בבית, מה חשוב לכם, כמה חדרים, איך נראה יום רגיל, ומה התקציב בערך)
```

**בלי Claude Code:** בשיחה רגילה ב-claude.ai אפשר לשלוח את הקישור למאגר, ו-Claude יקרא ממנו את השיטה ואת הכללים. אבל את הכלים הוא לא יוכל להריץ שם. לשרטוטים מדויקים ולהדמיה, השתמשו ב-Claude Code.

## פרטיות

- המאגר הזה ציבורי, ואין בו פרטים אישיים.
- הבריף שלכם יכיל פרטים אישיים ותקציב. לכן שומרים את העבודה בתיקייה במחשב, או במאגר פרטי משלכם. Claude יעזור לפתוח אותו.
- לא דוחפים למאגר הזה.
