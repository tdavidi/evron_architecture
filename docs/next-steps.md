# הצעדים הבאים

עודכן: (תאריך)

**המצב:** מתחילים. המאגר מוכן, והדוגמה נבנית בלי שגיאות.

1. **שלב 1, פרוגרמה ומגרש:** שיחת הפרוגרמה (`00-method.md`). ממלאים את `01-brief.md`, ומאשרים אותו עם המשפחה. כותבים את התקרה שלהם ב-`MAX_BUILT` שב-`tools/house_plan/lot.py`.
2. **שלב 2:** קודם חדרי החוץ והסמיכויות, אחר כך 3-4 צורות שונות באמת ב-`models.py`, עם הטקסטים ב-`texts.py`. כל צורה עוברת את רשימת הבדיקה והתרחישים לפני שמציגים.
3. **שלב 3:** סבבי הערות על הצורה שנבחרה, והדמיה בתלת-ממד.
4. **שלב 4:** חזיתות, חתך, גג, מערכות, וסיכום לאדריכל.
5. **לאורך הדרך:** מתאמים עם המשפחה השנייה את מה שמשותף (`open-questions.md`, "משותף לשני הבתים בזוג").
