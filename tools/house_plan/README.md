# כלי השרטוט, הבדיקה וההדמיה

מריצים מתיקיית השורש של המאגר, עם ה-Python של `.venv` (ההתקנה: `CLAUDE.md`).

| קובץ | מה הוא עושה |
|---|---|
| `models.py` | **הדגמים שלכם**: פונקציה לכל דגם, שמחזירה `Plan`. הרשימה `MODELS` קובעת את סדר הלשוניות בדף |
| `texts.py` | **הטקסטים שלכם**: הכותרת, הכרטיסים, ולכל דגם רעיון, בעד ונגד, הבית לאורך השנים וסבבי הערות. מספרים בסוגריים מסולסלים (`{שטח בנוי}`) מחושבים מהשרטוט |
| `build_page.py` | בונה את `deliverables/house/page.html`, את `share/page.html` לפרסום כ-Artifact, ואת התמונות. מריץ קודם את הבדיקות, ונעצר אם דגם שב-`CURRENT` נכשל. `build_page.py example` בונה את הדוגמה ל-`deliverables/example/` |
| `checks.py` | הבדיקות האוטומטיות (פירוט למטה). ממצא שמקבלים בכוונה: `p.waive = {code: reason}`. לבד: `checks.py <function>` |
| `draw.py` | המודל והשרטוט: חדרים כמלבנים (נטו), פתחים, ריהוט, גינה, גג ומסלולים. מצייר SVG בסגנון של תוכנית סקיצה, ויודע לשקף לתמונת מראה |
| `lot.py` | המגרש המייצג: מידות, קווי בניין, חניה, כיוון, והגבולות לבדיקה (160 מ"ר, 30% רעפים, פרגולה). את התקרה שלכם כותבים ב-`MAX_BUILT` |
| `house3d.py`, `house3d.js` | ההדמיה בתלת-ממד מאותו שרטוט: קירות עם פתחים, ריהוט לדוגמה, גינה, גג, מרפסת גג ומדרגות, ושמש לפי עונה ושעה. three.js נטען מ-CDN |
| `preview.py` | תצוגה מהירה של דגם אחד ותצוגה אחת, עם חיתוך לפי מטרים (`deliverables/preview/`, לא בגיט) |
| `shots3d.py` | תמונות של ההדמיה, ב-Chrome בלי חלון ומול שרת מקומי. רשות |
| `example_models.py`, `example_texts.py` | הדוגמה: חמשת הדגמים של הבית השני בזוג |
| `page.css` | העיצוב של הדף |

```bash
.venv/Scripts/python tools/house_plan/build_page.py
.venv/Scripts/python tools/house_plan/build_page.py example
.venv/Scripts/python tools/house_plan/checks.py form_patio_swap
.venv/Scripts/python tools/house_plan/preview.py form_patio_swap plan
```

## איך זה עובד

**מערכת הצירים:**
- **x** לאורך הרחוב, מהקיר המשותף (0) לצד הפנוי (18.5).
- **y** מהרחוב (0) לגינה (22).
- בשרטוט הרחוב למעלה, והצפון מוטה 17° שמאלה.
- הבית השני בזוג הוא תמונת המראה: התיבה "תמונת מראה" בדף מציירת כל דגם הפוך.

**קירות:**
- הקירות הם מה שנשאר בין החדרים. כל גוש בנוי (`blocks`) נצבע בצבע קיר, והחדרים מצוירים מעליו. לכן ברוטו פחות נטו שווה בדיוק לשטח הקירות.
- קו החוץ מצויר רק סביב האיחוד של הגושים. לכן הגושים לא חופפים, ופטיו הוא פשוט מקום שאין בו גוש.

**מידות:**
- קיר חוץ 25 ס"מ, ומחיצה 10 ס"מ.
- סביב הממ"ד רצועת בטון מקווקוות של 25-30 ס"מ, וצריך להשאיר לה מקום.
- כל קואורדינטה בכפולות של 5 ס"מ, כי ההדמיה פורסת את התוכנית על רשת של 5 ס"מ.

**פתחים:**
- `door`: חיתוך בקיר, עם ציר (`hinge`) וכיוון פתיחה (`into`). `kind="steel"` היא דלת ממ"ד.
- `slide`: דלת הזזה פנימית. `gap`: פתח בלי דלת.
- `window`: חלון. `"high"` הוא חלון גבוה, ו-`"glass"` דלת זכוכית נגררת.

**חדרי שינה:**
- הבדיקות מזהות חדר שינה לפי ה-id שלו: `parents`, `mamad`, וכל id שמתחיל ב-`kid` (`kid`, `kid2`...).
- `kind="mamad"` לממ"ד, `"wet"` לחדרים רטובים, `"circ"` למעברים, `"public"` לאזור היום.

**מסלולים:** `Plan.route(kind, *points, name=...)` מצייר הליכה בתצוגת המסלולים, עם האורך במטרים. סוגים: `alarm` (מהמיטה לממ"ד), `groceries`, `guest`, `laundry`.

**הבדיקות האוטומטיות:**
- מידות החדרים לפי התקנות, והממ"ד: 9 מ"ר, רוחב 1.60 ודלת פלדה שנפתחת החוצה.
- רוחב מעברים, ודלת שפוגעת בריהוט, בקיר או בדלת אחרת.
- המרווחים מול אסלה, כיור ומיטה זוגית.
- המדרגות: רום, שלח, 2ר+ש, מספר המדרגות במהלך, ומשטח ביניים.
- הכללים הקשיחים שאפשר למדוד:
  - המרחק מהמיטה לממ"ד.
  - חדר שינה שנפתח לסלון.
  - חדר שינה על הקיר המשותף.
  - 30% רעפים.
- תוויות שעולות זו על זו, או על ריהוט, קירות ודלתות. הן נקראות מה-SVG עצמו.
- הספים והמקורות: `docs/07-design-research.md`, סעיפים 4 ו-5.

**תמונות PNG:** נוצרות דרך MuPDF, שלא יודע לכתוב מימין לשמאל. לכן `bidi=True` הופך את סדר הטקסט העברי רק בשבילן. בדף ה-HTML הטקסט נשאר רגיל.

**התלת-ממד:**
- **הנחות גובה:** תקרה 2.75 מ', דלתות 2.1 מ', חלונות 0.9-2.1 מ', חלונות גבוהים 1.6-2.1 מ', וזכוכית לגינה עד 2.3 מ'.
- **גג:** הגג השטוח עם מעקה, והרעפים בשיפוע.
- **מפלסים:** החניה 0.7 מ' מתחת לבית, והגינה 0.1 מ'.
- **מבטים מבפנים:** לכל דגם, ב-`VIEWS3D` שב-`texts.py`, כמו בדוגמה.
